> Politique de confidentialité

Dernière mise à jour : 07 Septembre 2026.

Quelles données sont traitées ?

Lorsque vous utilisez cet outil, vous transmettez : le contenu du CV utilisé pour postuler (fichier PDF ou DOCX), le nom de l'entreprise, et le texte de la fiche de poste.

Pourquoi ces données sont traitées

Ces informations sont utilisées uniquement pour générer une préparation d'entretien personnalisée, via l'API d'Anthropic (Claude), qui agit ici comme sous-traitant technique.

Combien de temps sont-elles conservées ?

Aucune conservation. Le fichier et les textes fournis sont traités en mémoire, le temps de générer le document Word, puis immédiatement supprimés. Rien n'est stocké sur le serveur ni dans une base de données. Les échanges avec l'API Anthropic sont soumis à sa propre politique de rétention (consultez la politique de confidentialité d'Anthropic).

Qui a accès à ces données ?

L'exploitant de cet outil (komjordan.fr) et l'API Anthropic, dans le seul but de générer le document demandé. Aucune donnée n'est vendue, partagée ou utilisée à d'autres fins.

Vos droits

Comme aucune donnée n'est conservée après traitement, il n'existe pas de base de données à consulter, corriger ou supprimer. Pour toute question, contact : axel@komjordan.fr.

Cookies

Ce site utilise Google Tag Manager à des fins de mesure d'audience (le même que sur komjordan.fr). Aucun cookie de suivi publicitaire n'est utilisé. Votre préférence de thème clair/sombre est stockée localement dans votre navigateur, jamais transmise au serveur.
